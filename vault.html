Import a spreadsheet

Load a list of contacts or logins in one go. In Excel or Google Sheets, select the cells including the headings row, copy, and paste them here. Or choose a CSV file (Google Sheets: File › Download › CSV. Excel: File › Save As › CSV).

One row per vendor or site works best. Rows with the same name and companies become one entry with all their contacts. A Companies column can name several companies (“Slane, Filifera” or “All”) when they share one login. Nothing is saved until you check the preview and click Import.
